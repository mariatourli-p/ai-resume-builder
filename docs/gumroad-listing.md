## AI Resume Builder - React source code

A complete resume builder with free, on-device AI. Built with React 19, TypeScript, MUI and Redux Toolkit. No backend, no API keys and no AI bills: the AI is Gemini Nano, built into Google Chrome.

**Try the live demo first:** [demo link]. If the AI works there on your computer, it will work in the code you buy.

### What you get

- The full source code (React 19, TypeScript, Vite, MUI, Redux Toolkit)
- Sections: personal info with photo, work experience with dates, education, skills, courses & seminars, volunteering
- AI: Smart Rewrite for the summary, Generate Achievements, Suggest skills
- Live preview, accent colors and PDF export
- Data saved in the browser, with no server or database
- Storybook stories for every component, and a README explaining how the AI works

### Requirements - please read before buying

The editor, preview and PDF export work in any modern browser. **The AI features only work where Chrome's built-in AI is available:**

- A recent **desktop** version of **Google Chrome**. Safari, Firefox and phones are not supported.
- Windows 10/11, macOS 13+, Linux, or ChromeOS on a Chromebook Plus
- At least **22 GB** of free disk space (Chrome downloads the model once)
- A graphics card with more than **4 GB** of memory, or **16 GB** of RAM and 4 CPU cores
- An unmetered internet connection for the first download
- The AI writes in **English only**

To build and run the code: Node.js 18+ and basic knowledge of React.

### Good to know

- You are buying **the source code**. The AI itself is provided by Google through Chrome. Google decides which browsers and devices support it, and may change or remove it at any time.
- The AI can make mistakes. Your users should review what it writes.
- Using the built-in AI is subject to Google's [Generative AI Prohibited Use Policy](https://policies.google.com/terms/generative-ai/use-policy).
